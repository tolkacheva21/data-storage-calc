# Моделирование характеристик хранилищ данных

## Запуск

    pip install streamlit numpy pandas matplotlib
    streamlit run app.py

## Файлы

- `model.py` — расчёт: уравнения (2.9)–(2.21), возмущения ζ(t), целевая функция Z, чувствительность, генерация случайных данных
- `plots.py` — графики (динамика, ζ(t), зависимость Xi от Xj, зависимость от ζ, лепестковая диаграмма, сечения по времени)
- `app.py` — интерфейс (ввод данных, кнопки «Рандомизировать», результаты, графики, сохранение/загрузка конфигурации JSON)

## Что взято из документа

dXi/dt = (1/max Xi*) · [ произведение fk(Xj) и комбинация возмущений ζ1..ζ5 ] для i = 1..14.
Состав множителей и знаки при ζ в каждом уравнении прочитаны с формул документа.
Равны единице (по документу): f1(X1), f16(X2), f67(X6), f104(X10).

## Допущения (в документе не заданы)

1. fk(x) = a0 + a1·x + a2·x² + a3·x³ — коэффициенты по умолчанию 0.9; 0.2; 0; 0 (редактируются для каждой функции).
2. Множитель времени τ (по умолчанию 0.1) — масштаб скорости изменения показателей. Горизонт моделирования T = 1, шаг 0.05.
3. 1/max Xi* вычисляется как 1/Xi* (одно рекомендованное значение на показатель).
4. Целевая функция: Z = Σ γi·((Xi − Xi*)/(Xmax − Xmin))², Σγi нормируется на 1.
5. План мероприятий p(t): добавка ui к скорости изменения Xi начиная с момента t_старт.
6. Профили ζ(t): постоянный, ступенька, линейный, синусоида, импульс.
7. Xi ограничиваются отрезком [Ximin, Ximax].
8. Кнопки «Рандомизировать» задают случайные X(0), X*, профили ζ и коэффициенты f.

## Места, где формула в документе неоднозначна

- (2.12), X4: в записи множитель f56 стоит с аргументом X1; по нумерации (f43…f56 ↔ X1…X14)
  он относится к X14 — использован X14. Скобки прочитаны как P·ζ5 − (ζ1+ζ2+ζ3+ζ4 + f47(X5)·f48(X6)).
- Функции f76–f78 в документе используются и в уравнении X7, и в уравнении X8
  (разные аргументы) — в коде это разные функции, ключ — пара (i, j).
- Нумерация уравнений в документе дублируется (2.14, 2.17, 2.21) — в коде уравнения нумеруются по i.
